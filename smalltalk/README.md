# English Club · Small Talk

Локальная статическая страница по макету `english-club.html`. Открыть `index.html` в браузере; установка зависимостей и сборка не нужны.

- Мобильная компоновка по умолчанию, расширение сетки с 640 px.
- Разделы вопросов и русские переводы раскрываются через стандартные `details` / `summary`, без JavaScript. Нажатие на вопрос показывает перевод под ним; повторное нажатие скрывает.
- Georgia Pro с запасным Georgia для названия, системные шрифты для остального текста и CSS-иллюстрация, без внешних запросов.
- Сохранены вопросы и визуальный стиль исходного макета.

Перед публикацией нужно заполнить активности 1 и 2 и добавить реальные ссылки на чат, контакт организатора и запись. Пока они явно помечены как «скоро» и не являются ссылками.

Исходный макет не изменён. Коммиты и публикация не выполнялись.


Небольшая кнопка «Показать вопросы на русском» в каждом раскрытом блоке меняет основной язык всех его вопросов. Нажатие на отдельный вопрос показывает второй язык. Кнопки используют обычный JavaScript из `script.js`; без него доступны английские вопросы и раскрываемые русские переводы.


Файлы index.html, styles.css и script.js должны лежать рядом. CSS и JS подключены относительными путями, без модулей и загрузки через fetch: страница работает по file:// без локального сервера.


Для названия указан Georgia Pro с запасным системным Georgia. Georgia Pro локально не найден; для точного отображения нужен файл этого шрифта.
